# JS-Cookie-Challenge
Instructions:

Create a basic HTML page with the following elements:

A button that allows the user to set a cookie (e.g., their name or a favorite color).
A display area where the current cookie value will be shown.
A button that allows the user to delete the cookie.
Use JavaScript to:

Create a Cookie: When the user clicks the "Set Cookie" button, prompt them to enter their name (or favorite color). Save this information in a cookie with an expiration date of 1 day.
Read a Cookie: When the page loads, check if the cookie exists. If it does, display the stored value in the display area (e.g., "Welcome back, [name]").
Delete a Cookie: When the user clicks the "Delete Cookie" button, delete the cookie and clear the display area.
Your code should ensure:

Cookies are stored correctly and persist for one day.
If no cookie is set, the page should greet the user with a generic message (e.g., "Welcome, new user!").
Example:

If a user enters their name as "John" and clicks "Set Cookie", the page should remember their name and display a personalized message like "Welcome back, John!" when they return within the day.
Bonus (5 points):

Add a feature that changes the background color of the page based on the favorite color stored in the cookie.
